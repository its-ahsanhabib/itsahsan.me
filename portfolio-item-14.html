University Final Year Thesis

ABOUT THE PROJECT

Maximum MTU (Maximum Transmission Unite) Calculation for any link

Project Objective

We mainly analyzes the impact of the maximum transmission unit (MTU) on application performance. Simulation models are created and amount of experiments for typical FTP applications are conducted. Based on comparisons with different MTU value and different scenarios corresponding to the FTP upload response time, optimal settings are found. Optimal settings are required to achieve minimal delay in a network. We have studied and analyzed possible reasons for causing network delays. We have obtained theoretical explanation and basic formulas to understand basic mechanism of fragmentation, packet switching, header calculation, multiple delay calculations (like queuing delay, propagation delay, processing delay, and transmission delay). From those theoretical expressions, we found parameters like link capacity, number of hops, number of headers, header sizes, packet sizes, fragmentation, etc. we have varied these parameters to MATLAB based simulations and tried to determine the theoretical concept. We have experimented multiple times varying parameter and given best output results.
